AI Tools Trial

Tool evaluated per deliverable

Each artifact was tested across multiple tools. Chosen tool reflects best output quality, accuracy, and team accessibility.

Artifact Chosen Tool Reason Also Tried
Vision Documentation Liner Specialized in search, summaries, and organizing information — produced the best output Claude, Gemini
Requirements Specification Genspark Specialized in software development; produced better output than all alternatives Claude, Gemini (better than ClickUp & Copilot)
User Stories Claude Best fit for structured user story writing —
Use Case Diagram Eraser.io Best diagram output; prompt written with Gemini Mermaid (worst)
ERD Gemini + Eraser.io Gemini for description, Eraser.io for visualization — more accurate than alternatives ChartDB (paid, less accurate), Mermaid (less accurate)
API Documentation Antigravity + Claude Used Antigravity platform with Claude model to generate documentation —
Wireframes Figma AI Both Figma AI and v0 by Vercel produced accurate wireframes; v0 has low usage limits so Figma was used finally v0 by Vercel (good but limited)
Sprint Plan Notion Offers the most flexibility; team can all access and edit plans collaboratively Notion, Liner, Claude, Gemini (all tried)
Final Working MVP Replit Higher usage limits than Antigravity models — no need to switch between models mid-project Antigravity (multiple models tried)
Key notes from evaluation
  • Tools evaluated on: output quality, accuracy, feature availability, and team accessibility
  • Genspark outperformed Claude and Gemini for Requirements Specification due to software dev specialization
  • For ERD, a hybrid approach (Gemini + Eraser.io) gave the most accurate result — ChartDB requires payment
  • Figma AI preferred over v0 by Vercel for Wireframes due to v0's low usage limits
  • Notion chosen for Sprint Planning because it allows full team collaboration and editing flexibility
  • Replit preferred over Antigravity for the MVP because its higher limits eliminated model-switching mid-project
